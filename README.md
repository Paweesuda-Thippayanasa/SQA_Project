## Project Overview
This project is part of the Software Quality Assurance (SQA) course, conducted by Group 5. The objective of the project is to study the performance of Generative AI models in generating code for a dental clinic appointment system. The project involves manual and static testing to evaluate the quality of the produced code and its conformity to design patterns.

## Project Details
- **Project Name:** Generative AI Code Testing
- **Project Description:** This project analyzes the effectiveness of Generative AI models, such as ChatGPT, Gemini Pro, Gemini Flash, and GitHub Copilot, in generating code. The evaluation includes:
  - Code generation for a dental clinic appointment system
  - Manual testing of the generated code
  - Static analysis to assess code quality and adherence to design patterns
  

## Objectives
- Evaluate the accuracy and efficiency of AI-generated code.
- Compare different AI models in terms of code quality.
- Identify common issues in AI-generated code.
- Assess the usability and maintainability of AI-generated code.

## Tools & Technologies Used
- **AI Models:** ChatGPT, Gemini Pro, Gemini Flash, GitHub Copilot
- **Programming Languages:** Java, Python 
- **Testing Methods:** Manual Testing, Static Code Analysis
- **Other Tools:**  SonarQube, pylint, JUnit

## Project Scope
- AI-generated code evaluation for functionality and correctness.
- Testing methodologies including static analysis and manual review.

## Expected Outcomes
- A comprehensive report on the strengths and weaknesses of AI-generated code.
- Recommendations for improving AI-assisted coding in software development.


## Conclusion
This project aims to provide insights into the reliability of AI-assisted code generation for software development. Through structured testing and evaluation, we seek to determine how effectively AI can support software engineers in coding tasks.
